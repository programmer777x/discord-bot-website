Umineko Truths Feature

Render Umineko "Truth" statements as high-quality custom image cards directly in Discord.

Available Commands

  • /red [statement]: Render a Red Truth card (The ultimate truth).
  • /blue [statement]: Render a Blue Truth card (A hypothesis).
  • /gold [statement]: Render a Golden Truth card (The truth of the Game Master).

How it Works

Simply type the slash command followed by your statement. The bot will automatically generate an image with the appropriate theme and post it as a file attachment, ensuring perfect color rendering on all platforms.
